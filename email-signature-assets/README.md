# SAEAC email signature assets

The HTML signature uses the official SAEAC logo hosted at:

`https://senatorasuquoekpenyongacademicchampionship.com/brand/saeac-logo-blue-280.png`

Use the HTML version in a signature editor that preserves formatting. Use the
plain-text version for clients that do not support HTML signatures. Replace or
extend the contact lines only after the committee approves the official phone
number and address.

The public homepage no longer exposes live registration counts. Committee
members can still see those figures under the protected Admin → Reports page.
